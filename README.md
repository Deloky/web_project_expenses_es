# Gestor de gastos

Proyecto desarrollado como parte del Sprint 5 del programa de Desarrollo Web de TripleTen.

## Descripción

Gestor de gastos interactivo que permite establecer un presupuesto, registrar gastos en diferentes categorías y visualizar estadísticas relacionadas con los gastos realizados.

En este proyecto se trabajó principalmente con JavaScript para implementar la lógica y funcionalidad de una interfaz previamente desarrollada con HTML y CSS.

## Funcionalidades

- Establecer un presupuesto.
- Agregar nuevos gastos.
- Clasificar gastos por categorías.
- Calcular los gastos totales.
- Calcular el gasto promedio.
- Calcular el saldo disponible.
- Cambiar el color del saldo según el presupuesto restante.
- Calcular los gastos totales por categoría.
- Identificar la categoría con mayor cantidad de gastos.
- Mostrar y actualizar las estadísticas de gastos.
